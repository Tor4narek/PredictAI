# Контракты API

Файлы в этой директории генерируются из Go-контрактов и реестра MCP. Источник истины — код; вручную изменённые файлы будут перезаписаны.

| Файл | Содержимое |
| --- | --- |
| [`openapi.json`](openapi.json) | HTTP API Domain ↔ ESB: проверка состояния, типизированные тела вызовов всех агентов, чтение результатов и фактов. Также описывает GET с JSON-телом, который сохранён ради совместимости. |
| [`asyncapi.json`](asyncapi.json) | WebSocket `/stream` Константина: вопросы, подтверждения, ответы, первичный анализ и ошибки. |
| [`mcp-tools.md`](mcp-tools.md) | Краткий список MCP-инструментов для чтения. |
| [`mcp-tools.json`](mcp-tools.json) | Схемы `tools/list`, полученные напрямую от MCP-регистрации ESB. |

## Обновление

Из корня репозитория выполните:

```sh
make docs
make docs-check
```

OpenAPI строится из типов и метаданных в `esb/internal/presentation/httpapi/`. AsyncAPI использует те же типы сообщений, которые разбирает и отправляет WebSocket-обработчик. Каталог MCP извлекается через `tools/list` сервера, использующего тот же реестр инструментов, что и endpoint `/mcp`.

Краткие примеры и правила интеграции приведены в [руководстве Domain ↔ ESB](../integration.md). Архитектурные границы описаны в [документе об архитектуре](../architecture.md).
