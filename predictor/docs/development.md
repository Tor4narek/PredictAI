# Разработка

Все команды запускаются из корня репозитория.

| Команда | Что выполняет |
| --- | --- |
| `make lint` | Форматирует и проверяет производственный код ESB с помощью закреплённой версии golangci-lint. |
| `make test` | Запускает модульные тесты и сквозную проверку через ESB с изолированными PostgreSQL, ClickHouse, MinIO и имитацией Hermes. |
| `make test-unit` | Запускает модульные тесты без Docker; файлы тестов находятся в `predictor/tests/unit/`. |
| `make test-e2e` | Проверяет HTTP, WebSocket, MCP и хранилища; требуются Docker Compose v2 и запущенный Docker. |
| `make test-race` | Запускает модульные тесты с детектором гонок. |
| `make coverage` | Показывает покрытие модульными тестами по пакетам и общий процент; сквозные проверки в отчёт не входят. |
| `make build` | Собирает ESB. |
| `make docs` / `make docs-check` | Создаёт и проверяет документацию API и конфигурации. |
| `make tools` | Устанавливает golangci-lint версии `2.8.0`. |

`make lint` не проверяет тесты. Точечная директива `//nolint:<linter>` допустима с кратким объяснением; не добавляйте глобальные исключения только ради успешной проверки.

Тесты ESB хранятся за пределами Go-модуля `predictor/esb`. Скрипт `predictor/tests/run-unit.py` подключает их к исходным пакетам с помощью Go overlay, чтобы проверять в том числе непубличную логику. Сквозная проверка использует отдельный проект Compose и удаляет его контейнеры и тома после завершения.
